# Color system

No usamos pseudociencia de color. El color sirve a atención, jerarquía, identidad y accesibilidad.

## Parent palette

- Navy `#16233d` — autoridad calmada
- Paper `#f4efe4` / `#efe4d0`
- Sage `#4f7a62`
- Amber `#d4923c` — CTA adulta, nunca infantil de compra

## Child palette

- Cielo: `#163a4c → #6eaea4 → #f2c58a`
- Target saturado sobre fondo calmo
- Respuesta (glow breve) y retorno a calma
- Nunca saturación máxima en todo el frame

## Skill palette

Atención `#3F7A5A` · Memoria `#3D5A80` · Flexibilidad `#6A7F3A` · Patrones `#7A4E2D` · Espacio `#8A5A3B` · Lenguaje `#5B4E8A` · Números `#C4893A`

## Character

- Nilo: crema `#f4d2a2`, hoja `#5f8f4a`, semilla-luz `#f0c56a`
- Lumi: `#f4e287`
- Cami: verde cambiante
- Tiko: madera `#8a5a3b`

## Semántica (nunca solo color)

Semáforo: verde = cristal + icono “ir” + VO. Rojo = cristal + icono “esperar” + VO.

## Accesibilidad

Contraste en copy adulto ≥ 4.5:1. Child targets no dependen solo de matiz. `prefers-reduced-motion` y ajuste parental Motion: NORMAL / REDUCED.

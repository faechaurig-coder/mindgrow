# MindGrow

Plataforma lúdica para practicar y acompañar habilidades cognitivas y académicas tempranas (4–8 años).

No es un test de inteligencia. No diagnostica.

- Niño: “Haz crecer tu mundo.”
- Adulto: “Descubre cómo aprende y progresa.”

## Arranque

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

```bash
npm test
```

El estado vive en `localStorage` (`mindgrow.v1`). El botón `reset` (esquina) borra la demo.
